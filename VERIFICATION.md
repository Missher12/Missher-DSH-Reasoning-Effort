The checked package was subsequently published as the formal [v0.7.7 release](https://github.com/Missher12/Missher-DSH-Reasoning-Effort/releases/tag/v0.7.7); this section records its pre-publication validation. Release assets preserve the original package and its build-time documentation.

### Known limits recorded by the implementation

- A model row is writable only when the public `settingsSchema` service resolves the exact leaf and accepts the value. Without that service every row is read-only and says so; nothing is written on an unproven path.
- A built-in model can use `modelOverrides[id].reasoningEfforts` only when the route has no models list in its resolved configuration and the id belongs to the installed catalog. A route that declares its own models list is read-only here, because the Host rejects an override beside it.
- The page is registered only while the inline slot is absent; it is never shown next to the inline row.
- `configForms`, `settingsSchema`, `remote.llm` and `remote.session` are optional seats: a host missing one keeps the slider, model selection and guidance working, and the page reports the gap.
- Host answers are read through structurally validated shapes; a malformed answer degrades to "no models" with a message instead of throwing, and an incomplete mapping can never save an older value.
