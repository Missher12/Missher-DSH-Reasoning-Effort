# 修改要求

- 先读目标模型及路由的 `api`、`baseURL`，按端点文档确认实际支持的档位和值。参考档位与建议片段不是端点承诺，不确定时不要猜。
- 只修改目标模型的 `reasoningEfforts`，保留其它字段、路由和配置；不要重复添加 provider。
- 键限 `off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`，值须为端点实际取值，未声明的档位不可选。`off: null` 表示关闭时省略参数；`false` 表示没有可选档位，不保证端点内部完全不思考。不要写空对象。
- 仅在 `api: openai-completions` 且有端点文档或具体错误依据时添加 `compat`，不要凭通用 400 错误猜兼容开关。
- 保存后刷新模型目录，至少两档才显示滑块。说明实际改动与验证结果；滑块出现只证明目录读到声明，不能冒充真实请求验收。
